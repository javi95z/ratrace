# Art prompt pack: v2

Twenty sheets for what the game has grown since v1: five new careers and the lives that go with them, pictures for the work panel, icons for what things are good for, the cities in good times and bad, and a few moving parts.

Use it exactly as the v1 pack: the same ChatGPT project, the same **style block** (in `v1-prompt-pack.md`), and the approved sheet 01 attached to every request, starting the message with `Match the attached sheet's style exactly.` The checks before saving are the same.

Sheets are listed most useful first. Nothing in the game waits on any of them: each one replaces text or a stand-in that is there today.
