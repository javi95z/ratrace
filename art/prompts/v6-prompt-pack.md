# Art prompt pack: v6

A life for each of the four cities added in v5, three badges that belong to them, and two cards
that send a player abroad. Three sheets.

Use the same ChatGPT project and the same **style block** (in `v1-prompt-pack.md`). Attach the
sheet named in each section as the style reference, and start each message with
`Match the attached sheet's style exactly.` The checks before saving are the same as in v1.
